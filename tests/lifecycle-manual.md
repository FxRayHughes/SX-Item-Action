# 生命周期服务端验收

这些是待执行的场景，不代表已经通过。需要安装含本次改动的插件与 SX-Item，至少在实际目标 Paper 版本上验收。使用 `examples/lifecycle-items.yml` 创建测试物品。

| 场景 | 操作 | 预期 |
|---|---|---|
| 原版损耗与耐久条 | 创建 5000/10000 的剑，攻击；创建工具挖掘、护甲承伤 | 耐久条约一半，各自只扣 Bukkit 提供的损耗 |
| 耐久附魔 | 对照有/无耐久附魔的相同装备持续使用 | 不额外进行第二次随机减免，损耗总量服从原版事件 |
| 提前取消 | 由测试插件在 LOW 优先级取消损耗事件 | 自定义耐久和原版条均不减少 |
| 最后一点 | 剩余 1 的装备触发大于 1 的损耗，重复检查背包 | 只移除受损的一件；同材质/同编号其他槽位不受影响，损坏动作一次 |
| 修复 | 执行 repair；尝试铁砧、砂轮、工作台及经验修补 | 命令补满但不续期；原版转换/自定义耐久的经验修补受阻 |
| 首次生成 | 同编号两件物品间隔 3 秒生成，duration=10s | 两件有各自截止时间，分别到期；堆叠拆分继承同一期限 |
| 真实时间 | 到期前下线或关闭服务器，到期后上线 | 期限没有重置，登录清除已到期物品 |
| 更新持久性 | 损耗后改变 SX-Item Name/max/duration 并触发自动更新 | 名称更新，耐久与截止时间维持旧值，无重复耐久/日期 Lore |
| 使用边界 | 临近到期时点击、蓄弓、食用、换手、放置、破坏 | 到期后原版行为被取消，动作脚本不执行 |
| 容器与光标 | 放入箱子或末影箱后等待到期；光标持有、数字键换位、拖拽、Shift 点击 | 访问/扫描后清除，不能通过事务把已到期物品重新放入背包 |
| 地面物品 | 到期前丢出，到期后拾取；到期时丢出 | 掉落实体清除，无成功拾取动作或过期物品返还 |
| 非法输入 | max=0/current>max/2月30日/时长0、负数、超长整数、双期限字段 | 日志报告且阻止使用，物品不被误删；命令失败不改主手 |
| 状态损坏 | 将 SX-Attribute 改成字符串或删去一半耐久字段 | 不重新初始化恢复耐久或续期，报告异常并保留物品 |
| 动作等待 | 动作链首动作等待超过期限，再进入下一动作 | 不再启动下一动作；首动作内部已开始的逻辑不承诺中断 |
| 共享节点保留 | 添加其他 SX-Attribute 属性，扣耐久或命令续期；更新模板中的该属性 | 扣减/续期不丢属性，自动更新保留新属性值且不重置旧耐久/期限 |
| 配置模式 | 按原 CustomDurability/TimeLimit 示例生成物品，不手写 NBT | 在 SX-Attribute 中生成当前/最大耐久及到期毫秒值，原配置正常生效 |
| NBT 优先 | 消耗后修改配置初始耐久、时长和物品 Lore，触发 update | 仍使用保存的耐久和期限，不恢复或续期；显示模板可更新 |
| Lore 兼容 | 无配置/状态时使用中英文冒号的兼容 Lore；初始化后再改 Lore 数字 | 初次导入成功，后续按 SX-Attribute 中保存的状态判断 |
| SX 原生变量 | 显示使用 <s:value>/<s:max-value>，current 使用 <c:int <s:max-value> / 2> | 数值来自 NBT，初始值和显示经过 SX 嵌套解析，扣减后正确刷新 |
| SX 日期格式 | 使用默认 TimeFormat 测试固定日期；修改 SX TimeFormat 并按 SX 要求重载/重启 | 日期显示跟随 SX 格式，原 NBT 截止时间不变；新固定日期按 SX 格式解析 |
| SX 时间变量 | expires-at 使用 <t:7d>，显示使用 <s:time>，多次扫描和 update | 截止时间只初始化一次，不重新续期；显示精度服从 SX TimeFormat |
| SX Random 与玩家上下文 | 初始 max 引用物品 Random，显示附加全局变量或玩家占位符 | 使用 SX 的局部/全局解析逻辑；玩家事件、定时和命令均能取得对应玩家 |
| 整行位置 | Lore 中间放入 <l:CustomDurability> 与 <l:TimeLimit>，前后加入文字和空行 | 生成后对应位置显示完整模板，标记不泄露，不在末尾重复追加 |
| 整行刷新 | 耐久消耗、repair、timelimit 后检查 Lore | 所有引用位置都刷新，说明文字和其他插件追加行保持原样 |
| 重复与混排行 | 重复引用耐久变量，并测试同一行包含两个变量或前后文字 | 各处均更新，前后文字保留，不只更新第一处 |
| 整行 update/reload | 改变 Lore 顺序，执行 /si reload 并触发 SX update，再生成新物品 | 变量重新注册，按新顺序显示，旧耐久和期限不重置 |
| 空功能与旧配置 | 没有 TimeLimit 时引用整行变量；旧配置不写整行变量 | 无对应功能不显示内部标记；旧配置仍按原行为追加显示行 |
